# 本地相框内窗适配验证（2026-09-15）

## 实现范围

在统一的 `_render_layers` 入口，对已有 `attachment.slot_id` 且位于照片上方的装饰分析透明区域。仅当找到单个面积足够大、与所属照片位置相符的封闭内窗时，照片才按实际内窗 cover 拟合并裁剪。照片与相框共用相框的局部画布及旋转中心，仍按原 layer_order 合成。

- 不读取素材名字或标签来推断相框，不新增 VLM 字段或模型请求。
- 不改写 TemplateSpec、照片归属关系、用户缩放/平移/anchor 或原素材。
- 使用现有 Pillow，按行扫描 alpha 连通区域，不依赖 OpenCV。
- 缓存以最终拟合 alpha 像素及尺寸为键，素材/拟合结果变化自动失效。最多缓存 16 项、每项不超过 1024² 像素，大尺寸走相同检测但不缓存；缓存 alpha 和 mask 合计上限约 32 MiB。
- 仅处理非背景、mode=photo、fit=cover、无显式 clip_mask 的照片。开放边框、无透明内窗、小孔、多内窗、多个相框候选、与照片不相交等情况保留原渲染行为。

检测是几何启发式：alpha >= 128 视为边界，主内窗至少占局部画布 10%，较大的第二内窗会导致跳过；窗口面积须为原照片面积的 0.25–2 倍，且重叠面积至少达到较小者的 60%。这些阈值用于保守筛选，不保证任意装饰都能正确识别。
